This is one of my favourite projects. While I would have loved to be able to create this whole project without any assistance from AI, it is still amazing. I really found that there was so much creating an application for others, especially ranging from adults, all the way to the younger years.

It is very complex, with Backstage Show dashboards, attendance roster, iCal Live Calendar link, calendar, "/parents" routes, announcements, WhatsApp Intergration, OTP Sign-In using email, secret logins... (oooh), multi-layer protection etc etc! 

Luckily, this project made me notice how many people can use projects. Even though it is made using AI, I am still proud of how it was made, and the active upgrades I am doing to it. So many people rely on and use my software and it is just incredible. 

Many thanks to Josh & Felix M, Leila P and Adam M for all the assistance finding the bugs, feature requests and just overall amazing help!
