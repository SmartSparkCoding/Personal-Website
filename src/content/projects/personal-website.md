Oh - this looks familiar! This is the site you are currently on! This is my personal website and portfolio, built to showcase my work, projects, interests and journey as a student and developer.

The website is built with Astro and uses a content-driven architecture to make managing projects simple. Projects are stored as Markdown files and automatically appear on the portfolio page, with individual project pages generated dynamically from the project data. The site also includes reusable components such as a global navigation bar and footer, alongside dedicated sections for my introduction, projects and contact information.

The website is designed to grow alongside me as I continue learning and building new things. Rather than manually creating a new page for every project, I can add a new project to the content collection and the website automatically generates the relevant portfolio card and project page.

This project has allowed me to explore modern web development, Astro, responsive design, content management and UI/UX while creating a central place to share the things I build and the technologies I enjoy working with.
