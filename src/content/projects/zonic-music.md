## Project Info

Zonic runs Amazon Music's own web player inside a native WebKit window, then adds the things a browser tab does not do well: a real app in the dock, working media keys, Control Center, a titlebar worth looking at, themes that reach the page, a lyrics screen, and updates that install themselves. About 1 MB of binary, no Electron, no background daemons, no second browser.

It is inspired by how (Slick)[https://slickclient.net] was made (by (3kh0)[https://github.com/3kh0/] and challenged me to go completely out of my comfort zone with only Agents to help me make this. 

It started out as a silly simple idea, but then I realised the potential. This has been really fun and I can't believe it has worked out like this. 

## Note

This project was built with Gorkie, and OpenCode, both of which are an AI assistant. The code, the releases and this README were written by AI, with Jacob directing, testing and deciding what ships. Every build is built and published by GitHub Actions from the source in this repo, so you can read exactly what you are running.
