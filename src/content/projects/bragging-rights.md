Bragging Rights is a full stack application I am building to track competitive board game results between players (my family).
The web application inlcudes player profiles, each with pins, game statistics, leaderboards and a flexible database system designed to support different types of games, like Scrabble or Monopoly and scoring systems.
The project has allowed me to explore full-stack development beyond simple websites, made for myself, while exploring backend devlopment and how different aspects of a site impacts the user and their understanding of a web application.
