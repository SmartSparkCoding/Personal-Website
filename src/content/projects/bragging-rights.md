Bragging Rights is a full-stack application I am building to track competitive board game results between players, primarily my family.

The web application includes player profiles, each with PINs, game statistics, leaderboards and a flexible database system designed to support different types of games, such as Scrabble or Monopoly, alongside different scoring systems.

The project has allowed me to explore full-stack development beyond simple websites made for myself. I have been able to work with backend development, databases and application architecture, while learning how different aspects of a website impact the user experience and their understanding of a web application.
